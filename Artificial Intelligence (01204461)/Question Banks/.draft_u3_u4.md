## Unit 3

**28.** A retailer holds years of purchase histories but has never defined customer categories. What makes this an unsupervised learning problem?

A. The dataset contains a target column, but too few rows carry a label for supervised training to work.
**B. The dataset contains only $x$, so the algorithm must propose structure instead of learning a rule $x \to y$.**
C. The dataset contains $(x, y)$ pairs whose labels are known to be noisy and must be corrected before training.
D. The dataset contains a target column that is revealed only after the model has made its predictions.

**Explanation:** Unsupervised learning works from $D = \{x_i\}$ with no target column, so the algorithm proposes structure and you judge whether it is useful. There is no ground-truth $y$ to be right or wrong about.

**29.** Two articles cover the same topic, but one is 200 words and the other is 2,000. Which metric treats them as nearly identical, and why?

A. Euclidean distance, because it sums the squared differences across every coordinate of the two vectors.
B. Manhattan distance, because using absolute differences stops any single long document from dominating.
C. Squared Euclidean distance, because squaring the coordinate gaps cancels the effect of differing lengths.
**D. Cosine similarity, because it measures the angle between the vectors and ignores their magnitudes.**

**Explanation:** The longer document's vector is roughly ten times longer, so Euclidean-family metrics place the two far apart, but both vectors point in nearly the same direction. Cosine is the right choice whenever vector size is an artifact rather than signal.

**30.** A point has fewer than $\mathrm{MinPts}$ neighbours inside its own $\varepsilon$-ball, but it lies inside the $\varepsilon$-ball of a point that does meet the threshold. How does DBSCAN label it?

A. Core, because it lies within $\varepsilon$ of a point that already satisfies the density threshold.
B. Noise, because any point whose own neighbourhood is smaller than $\mathrm{MinPts}$ is left unassigned.
**C. Border, because it fails the density count yet sits inside some core point's $\varepsilon$-ball.**
D. Border, but only if at least $\mathrm{MinPts}$ other border points also lie inside its own $\varepsilon$-ball.

**Explanation:** The border test has two parts: fail the count, but fall inside a core point's radius. Border points join a cluster without being able to extend it; failing both parts is what makes a point noise.

**31.** A scree plot reports cumulative explained variance of $48\%$, $72\%$, $84\%$, $91\%$, and $95\%$ for the first five components. What is the standard way to choose $k$?

**A. Keep the smallest $k$ whose cumulative EVR reaches roughly $90\%$–$95\%$ of the total variance.**
B. Keep every component whose individual EVR is above the average EVR taken over all components.
C. Keep all of the components, since the cumulative curve only reaches $100\%$ when nothing is discarded.
D. Keep the $k$ at which the cumulative curve stops rising, since components beyond it add no variance.

**Explanation:** EVR turns "how many components?" into a budget question, and standard practice is the smallest $k$ reaching about $90\%$–$95\%$ — here $k = 4$ at $91\%$. The cumulative curve never stops rising, so option D has no cut point.

**32.** A classmate defines k-Means as "the loop that assigns every point to its nearest centroid and then recomputes the means." What does that definition leave out?

A. The Voronoi regions, which k-Means computes and stores alongside the centroids and assignments.
B. The initialization rule, which is the only stage of the procedure that actually lowers the distortion.
C. The requirement that memberships be fractional, which the assignment step imposes on each $r_{ik}$.
**D. The SSE objective $J$, which defines what counts as a good clustering; the loop is only the search for it.**

**Explanation:** Two different things share the name k-Means: the objective $J(R,\mu) = \sum_i \sum_k r_{ik}\lVert x_i - \mu_k\rVert^2$, and Lloyd's algorithm that searches for a low-$J$ solution. Memberships are binary, and the Voronoi shading in the figures is decoration that the algorithm never stores.

**33.** Why does the k-Means objective square the distance $\lVert x_i - \mu_k \rVert$ rather than using the plain distance?

**A. Because the point minimizing total squared distance to a group is its mean, which turns the update step into a simple average.**
B. Because the point minimizing total squared distance to a group is its median, which is easier to locate than the mean.
C. Because squaring compresses the large distances and so limits how much outliers can move a centroid.
D. Because squaring makes the objective convex, so wherever the loop stops is guaranteed to be the global optimum.

**Explanation:** Squared distance is what makes the optimal representative the mean; plain distance would give the median instead. Squaring also makes far points cost more (4 units away contributes 16), so outliers pull centroids rather than being suppressed, and $J$ remains non-convex.

**34.** Lloyd's algorithm is guaranteed to stop, yet it can stop at a visibly poor clustering. Which explanation covers both facts?

A. Every iteration lowers $J$ by a fixed amount, which forces termination, but floating-point rounding keeps it from reaching the optimum.
B. $J$ is convex in the assignments and the centroids jointly, which forces termination, and poor results come only from choosing the wrong $K$.
**C. Each step can only lower or hold $J$ and the assignments are finite, which forces termination, but $J$ is non-convex so the resting point is a local minimum set by the seeds.**
D. The dataset is finite, which forces termination, and poor results come from updating the centroids before the assignments have been refreshed.

**Explanation:** Both steps minimize $J$ over one variable with the other fixed, and $J \ge 0$ with only $K^n$ possible assignments, so the process must settle. Because $J$ is non-convex, that settling point is a local minimum determined by the initialization — a bad seed is a local minimum the loop cannot escape.

**35.** k-Means++ draws each new seed with probability proportional to $D(x)^2$ instead of simply taking the point farthest from the seeds chosen so far. Why keep the choice probabilistic?

A. Because a deterministic rule would require every pairwise distance in the dataset, which costs more than sampling does.
**B. Because the point farthest from everything is usually an outlier, so weighting by $D^2$ makes distant points likely without making them certain.**
C. Because the randomness lets Lloyd's algorithm settle into a different local minimum on each run, which is then averaged.
D. Because the squared weighting guarantees exactly one seed inside every true cluster, which a deterministic rule cannot do.

**Explanation:** Deterministically grabbing the farthest point would seed a garbage centroid on an outlier every run, so $D^2$ weighting buys spread without systematically seeding on noise. Note the wording trap: the lecture key says "exponentially" more likely, but the formula is quadratic.

**36.** Why is "pick the $K$ with the lowest SSE" a useless criterion, and what does silhouette analysis add that the elbow method does not?

A. SSE is undefined at $K = 1$, so the elbow must start at $K = 2$; silhouette adds robustness because it discards ambiguous boundary points before scoring.
B. SSE rises as $K$ rises, so the elbow looks for the first sharp increase; silhouette adds cohesion because it averages the distances inside each cluster.
C. SSE depends on the initialization, so the elbow has to average several runs; silhouette adds determinism because it scores medians rather than means.
**D. SSE always falls as $K$ rises, so the elbow looks for diminishing returns; silhouette adds separation because it compares a point's own cluster with the nearest other one.**

**Explanation:** SSE reaches zero at $K = n$, so the minimum is meaningless and the elbow instead marks where extra clusters stop paying. Silhouette uses $a(i)$ for cohesion and $b(i)$ for separation, which is why it produces a sharp peak while the elbow stays a judgement call.

**37.** Two dense, well-separated clusters are connected by a thin trail of noise points. Single linkage merges them into one cluster, while complete, average, and Ward keep them apart. Why?

**A. Single linkage scores a pair of clusters by their closest pair of points, so a chain of near neighbours can bridge the gap.**
B. Single linkage scores a pair of clusters by their farthest pair of points, so the trail shortens that maximum distance.
C. Single linkage merges whichever pair raises the total within-cluster spread the least, and the trail keeps that increase small.
D. Single linkage averages the distances over all cross-cluster pairs, so the many trail points drag that average down.

**Explanation:** With $D(C_A, C_B) = \min_{x,y}\lVert x - y \rVert$, any single close pair is enough to trigger a merge, which is the chaining effect. The flexibility that lets single linkage follow long curved shapes is exactly what makes it fragile to noise.

**38.** A fraud team wants to review the genuinely ambiguous accounts first. Why is a GMM more useful here than k-Means?

A. A GMM discovers $K$ from the data, so ambiguous accounts never have to be forced into a preset number of segments.
B. A GMM labels the low-probability accounts as noise, so the ambiguous ones are filtered out automatically before review.
**C. A GMM returns a membership probability per cluster summing to one, so a borderline account is reported as $70\%$/$30\%$ instead of being forced into one label.**
D. A GMM maximizes a convex likelihood, so its clusters are globally optimal while k-Means only reaches a local optimum.

**Explanation:** Hard assignment destroys the information that a point was a coin flip; soft membership $\gamma_{ik}$ reports it, which is the whole value when boundary cases are the interesting ones. A GMM still requires $K$ as an input, and explicit noise labelling is DBSCAN's feature, not the GMM's.

**39.** Which pair correctly states why DBSCAN separates two concentric rings and where that same design breaks down?

A. It succeeds because it fits a separate radius to each ring, and it fails on elongated clusters because the $\varepsilon$-ball is identical in every direction.
**B. It succeeds because it only ever asks which points are immediate neighbours, and it fails when clusters differ in density because one global $(\varepsilon, \mathrm{MinPts})$ assumes uniform density.**
C. It succeeds because it raises the cluster count until the distortion stops improving, and it fails once that count grows large enough to be intractable.
D. It succeeds because outliers are excluded when its centroids are computed, and it fails when those outliers form a dense region of their own.

**Explanation:** Local questions survive curvature: a point on the inner ring only ever neighbours inner-ring points, whereas distance-to-centre is identical for two rings sharing $(0,0)$. The mirror image of that strength is that a single global $\varepsilon$ cannot fit one dense and one sparse cluster at the same time.

**40.** Which description of high-dimensional geometry correctly explains why distance-based clustering degrades as $d$ grows?

**A. Almost all of a hypercube's volume moves into its corners, and $(d_{\max} - d_{\min})/d_{\min} \to 0$, so the nearest and farthest neighbours become nearly equidistant.**
B. The inscribed hypersphere takes up a growing share of the cube, so points crowd toward the centre and every distance shrinks toward zero.
C. Pairwise distances grow without bound while their ratios stay fixed, so distances overflow numerically before they lose their meaning.
D. Distances stay just as informative, but the number of possible clusterings grows exponentially with $d$, making the search intractable.

**Explanation:** The curse has two faces: the sphere fills $78.5\%$ of the cube at $d = 2$ but under $0.25\%$ at $d = 10$, and the spread between the closest and farthest pair collapses relative to the distances themselves. Both attack the assumption that "close" and "far" still mean something.

**41.** PCA is described both as maximizing retained variance and as minimizing squared reconstruction error. Why are these the same objective?

A. Because the components are mutually orthogonal, the reconstruction error is zero for any $k$, so both criteria are satisfied automatically.
B. Because eigenvalues are non-negative, the dropped eigenvalues always sum to the kept ones, which makes the two criteria mirror images.
**C. Because the projection and the residual are orthogonal for centred data, $\lVert x\rVert^2$ splits into kept variance plus lost error while the total stays fixed.**
D. Because the covariance matrix is symmetric, its eigenvectors minimize the error while its eigenvalues separately maximize the variance.

**Explanation:** Pythagoras gives $\lVert x_i\rVert^2 = \lVert z_i\rVert^2 + \lVert x_i - \hat{x}_i\rVert^2$, and the left-hand side is fixed by the data, so every unit of variance kept is a unit of error avoided. The lecture's run confirms it numerically: dropping PC2 left MSE $0.3727 \approx \lambda_2 = 0.3790$.

**42.** An MLP has three hidden layers, all using the identity activation $f(z) = z$. Why is it no more expressive than a single linear layer?

**A. Composing affine maps produces another affine map, so the whole network reduces to $W_{\mathrm{combined}}x + b_{\mathrm{combined}}$.**
B. Identity activations drive all of the weight matrices toward the same values as training progresses.
C. The derivative of the identity is one, so backpropagation ends up updating only the final layer's parameters.
D. The biases cancel each other across the layers, leaving a network that passes its input through unchanged.

**Explanation:** The product of matrices is itself a single matrix, so depth buys nothing without a nonlinearity; the network is mathematically equivalent to one linear layer regardless of how many layers are stacked. Non-linear activations are what let each layer fold the space.

**43.** You are building a network that sorts images into ten mutually exclusive classes. Which output activation and loss does the chapter pair for this task?

A. Sigmoid with binary cross-entropy, applied independently to each of the ten output units.
B. Identity with mean squared error, treating the ten class indices as continuous targets.
**C. Softmax with categorical cross-entropy, applied to the ten logits against a one-hot label.**
D. Softmax with mean squared error, applied to the ten normalized probabilities against a one-hot label.

**Explanation:** Each task type is a locked pair: identity + MSE for regression, sigmoid + BCE for binary, softmax + CCE for multi-class. All three pairings conveniently give the same output gradient $\partial L/\partial z = \hat y - y$.

**44.** Which of the following is a hyperparameter rather than a parameter?

A. The weight matrix $W^{(l)}$, which gradient descent adjusts at every update step.
**B. The batch size $B$, which you fix before training begins and which gradient descent never adjusts.**
C. The bias vector $b^{(l)}$, which is updated from its own gradient at every step.
D. The pre-activation $z^{(l)}$, which is recomputed from the current weights on every forward pass.

**Explanation:** The test is whether gradient descent updates the value automatically: if yes it is a parameter ($W$, $b$), and if you typed it in before training it is a hyperparameter. Batch size joins $\eta$, epochs, optimizer, architecture, and the choice of activation.

**45.** In $z = w^\top x + b$, what does each of $w$ and $b$ do to the decision boundary?

A. $w$ slides the boundary away from the origin, while $b$ tilts it into a new orientation.
B. $w$ sets how thick the boundary is, while $b$ sets the gap between the two classes.
C. $w$ and $b$ both tilt the boundary, and only their product decides where it finally sits.
**D. $w$ is normal to the boundary and therefore rotates it, while $b$ slides it parallel to itself.**

**Explanation:** The weight vector is the arrow poking out perpendicular to the wall and pointing into the $\hat y = 1$ side, so turning it tilts the wall. Changing $b$ shoves the wall away from the origin at the same angle, a distance $\lvert b\rvert/\lVert w\rVert_2$.

**46.** Why could Rosenblatt not train the classical perceptron with gradient descent, which forced him to write an error-correction rule by hand?

A. The step function is undefined for negative pre-activations, so the loss cannot be evaluated on that side.
**B. The step function's derivative is zero everywhere except the jump, where it is undefined, so there is no direction to follow.**
C. The step function emits only $0$ or $1$, so the loss cannot be written as a differentiable function of the labels.
D. The step function saturates for large $\lvert z \rvert$, so its gradient shrinks toward zero as training goes on.

**Explanation:** Gradient descent asks "if I nudge this weight, does the loss move?" and a flat step always answers "nothing changes," so no learning signal exists. Saturation in option D is the sigmoid's problem, not the step's.

**47.** Applying $w \leftarrow w + \eta(y_i - \hat y_i)x_i$ first to a correctly classified example and then to a false negative ($y_i = 1$, $\hat y_i = 0$), what happens in each case?

A. Both examples move $w$, but the correct one moves it less, by an amount proportional to the prediction's confidence.
**B. The correct example leaves $w$ untouched, and the false negative rotates $w$ toward $x_i$.**
C. The correct example rotates $w$ toward $x_i$, and the false negative leaves $w$ untouched until the bias is updated.
D. The correct example leaves $w$ untouched, and the false negative rotates $w$ away from $x_i$.

**Explanation:** The error term $y_i - \hat y_i$ takes only the values $0$, $+1$, and $-1$, so correct predictions contribute nothing and leave the wall still. A false negative adds $\eta x_i$, rotating $w$ toward the missed point; a false positive subtracts it and rotates away.

**48.** A student proposes swapping a single neuron's step activation for a sigmoid in order to solve XOR. Why does this fail?

**A. $\sigma(w^\top x + b) = 0.5$ exactly when $w^\top x + b = 0$, so the boundary is the same flat wall and the probability contours run parallel to it.**
B. The sigmoid saturates on XOR's inputs, so every output sits near $0.5$ and no decision boundary can be defined at all.
C. The sigmoid does curve the boundary, but the curve bends around the wrong corner unless the bias is retrained first.
D. The sigmoid emits probabilities rather than labels, so the perceptron learning rule can no longer be applied to it.

**Explanation:** A nonlinear output value is not the same thing as a nonlinear boundary — the $P = 0.5$ cut is still a straight wall, with the $0.1$/$0.3$/$0.7$/$0.9$ contours parallel to it rather than curving around $(1,1)$. Only a hidden activation changes the space itself.

**49.** In the two-layer XOR network, $h_1$ computes OR, $h_2$ computes AND, and the output unit computes $h_1 - 2h_2 - 0.5$. What makes this construction work?

A. The hidden units draw two separate curved boundaries in $(x_1, x_2)$, and the output unit picks between them.
B. The hidden units apply a nonlinear squashing to the output, and that squashing is what makes the raw inputs separable.
**C. The hidden layer sends both XOR-positive inputs to the same point $(1,0)$, so one straight boundary separates the classes in $(h_1, h_2)$.**
D. The $-2h_2$ term makes the output boundary quadratic in $x_1$ and $x_2$, which lets it enclose the point $(1,1)$.

**Explanation:** Hidden layers move the points and the output layer then cuts them with the plane $h_1 - 2h_2 - 0.5 = 0$; the $-2h_2$ term cancels $h_1$ whenever AND fires, knocking $(1,1)$ back below zero. The network never draws a curve in the original $x$ space.

**50.** Why is ReLU the default for hidden layers, and what is the dying-ReLU problem?

A. ReLU is zero-centred while sigmoid is not; a unit dies when its output saturates at a large positive value and stops changing.
**B. ReLU passes a gradient of $1$ for positive inputs while sigmoid's slope peaks at $0.25$ and vanishes in the tails; a unit dies when $z \le 0$ on every example, leaving its gradient permanently zero.**
C. ReLU is bounded above which keeps activations in range; a unit dies when its weights grow until the activation overflows numerically.
D. ReLU is differentiable everywhere unlike sigmoid; a unit dies when the learning rate is too small to push it out of the flat region.

**Explanation:** Sigmoid in hidden layers is how gradients vanish, whereas ReLU keeps full gradient on the positive side and is cheap to compute. A unit whose pre-activation is never positive has $\phi' = 0$ forever and never updates, which Leaky ReLU and PReLU address by keeping a small slope $\alpha$ on the left.

**51.** Backpropagation gives $\partial L/\partial W^{(l)} = \delta^{(l)}(a^{(l-1)})^\top$ and $\partial L/\partial b^{(l)} = \delta^{(l)}$. What do these two expressions say in words?

A. Each weight's gradient is the neuron's error divided by the activation feeding it, and the bias gradient is that error scaled by the learning rate.
B. Each weight's gradient is the activation feeding it times the next layer's weight, and the bias gradient is the sum of the layer's errors.
C. Each weight's gradient is the neuron's error times the weight's own current value, and the bias gradient is the error times the mean input.
**D. Each weight's gradient is the receiving neuron's error times the activation that fed that weight, and the bias gradient is just the error, because the bias has no multiplier.**

**Explanation:** Since $z = \sum_k W_k a_k + b$, the sensitivity of $z$ to a weight is the activation it multiplies, while $\partial z/\partial b = 1$. That is why a bigger input earns a bigger share of the blame, as when $a_2 = 0.609$ drew a larger gradient than $a_1 = 0.593$ in the worked example.

**52.** Training loss keeps falling while validation loss has been rising for several epochs. Which response addresses the actual problem?

**A. Add L2 weight decay, apply dropout, or stop early and restore the best-validation parameters, because the problem is overfitting.**
B. Apply gradient clipping, because a rising validation loss shows that the gradients have started to explode.
C. Switch the hidden activations to sigmoid, because a rising validation loss shows that the gradients have started to vanish.
D. Re-initialize the weights with He initialization, because a rising validation loss shows that the starting scale was wrong.

**Explanation:** Falling train loss with rising validation loss is the definition of overfitting, and the three hammers for that nail are L2, dropout, and early stopping. Clipping, initialization, and normalization address gradient scale, which is a separate problem.

**53.** How do batch gradient descent ($B = n$), stochastic gradient descent ($B = 1$), and mini-batch gradient descent differ?

**A. They share the update rule and differ only in how many samples estimate $g_t$: BGD is stable but expensive, SGD is cheap but noisy, and mini-batch balances the two while fitting GPU parallelism.**
B. They differ in the update rule itself: BGD subtracts the gradient, SGD subtracts a random gradient, and mini-batch subtracts an average of both quantities.
C. They differ in the learning rate they require: BGD needs the largest $\eta$, SGD the smallest, and mini-batch a value somewhere between the two.
D. They differ in the number of epochs they need: BGD needs one epoch per update, SGD needs $n$ epochs, and mini-batch needs $\lceil n/B \rceil$ epochs.

**Explanation:** All three run $\theta_{t+1} = \theta_t - \eta g_t$; only the sample count behind $g_t$ changes. SGD's noise is not purely a downside either, since it can shake the optimizer out of a shallow dip, but mini-batch sizes such as $32$ or $64$ are the practical standard.

**54.** How does dropout behave at training time versus test time, and why does it help?

A. Units are dropped at training and at test time alike, so the prediction ends up averaged over many thinner networks.
**B. Units are dropped with probability $p$ during training only and all units are active at test time, so the network cannot lean on a fixed clique of neurons.**
C. Weights rather than units are zeroed during training and restored at test time, which shrinks the effective magnitude of the weights.
D. Units are dropped at test time only, which measures how strongly the prediction depends on any individual neuron.

**Explanation:** Each training step samples a different thinner network, forcing features that still work when partners are missing, which is what blocks co-adaptation. Inference uses the full network; the cost of the method is slower training.

**55.** Both $w$ and $b$ of a trained neuron are multiplied by $3$. What happens to its decision boundary and its outputs?

A. The boundary rotates toward the direction of $w$ while the outputs are unaffected, since only the bias sets the offset.
B. The boundary moves three times farther from the origin, because the shove $\lvert b \rvert$ applied to it is now three times larger.
C. The boundary becomes three times wider as a band, so points lying near it are now classified with lower confidence.
**D. The boundary is unchanged, since $3w^\top x + 3b = 0$ describes the same set; only $z$ is rescaled, which alters confidence rather than predictions.**

**Explanation:** Only the direction of $w$ matters for the tilt and only the ratio $b/\lVert w\rVert_2$ matters for the shift, so scaling both by the same factor leaves the wall exactly where it was. The distance from the origin, $\lvert b\rvert/\lVert w\rVert_2$, is unchanged for the same reason.

**56.** The Universal Approximation Theorem says one hidden layer with enough units can approximate any continuous function on a bounded domain. Why do practitioners still build deep networks?

**A. The theorem guarantees such a network exists but not that gradient descent will find it, and the required width can explode, whereas depth builds hierarchical features far more efficiently.**
B. The theorem holds only for sigmoid units, so extra layers become necessary whenever ReLU is used in the hidden layers.
C. The theorem bounds the average error over the domain rather than the worst case, so extra layers are needed to control the worst input.
D. The theorem applies only to unbounded domains, so real datasets need extra layers to compensate for their bounded feature ranges.

**Explanation:** UAT is an existence theorem, not a training guarantee, and a shallow network may need an impractically large $M$. Its error bound is already worst-case — the $\sup$ over $x \in K$ — and it holds for any suitable nonlinearity, including ReLU hinges.

**57.** In $\delta^{(l)} = (W^{(l+1)})^\top \delta^{(l+1)} \odot f'(z^{(l)})$, what does each factor contribute, and how does the equation explain vanishing gradients?

A. The transposed weights rescale the error to unit length and $f'(z^{(l)})$ fixes its sign; gradients vanish when those signs alternate from layer to layer.
B. The transposed weights hold the cached activations and $f'(z^{(l)})$ holds the cached pre-activations; gradients vanish when that cache is dropped to save memory.
**C. The same forward weight carries the error back and the local slope $f'(z^{(l)})$ gates how much of it gets through; repeating that product across layers drives $\delta$ toward zero when the factors are small.**
D. The transposed weights accumulate the error over the batch and $f'(z^{(l)})$ divides it by the batch size; gradients vanish when the batch grows too large.

**Explanation:** If $a_1$ changes by one unit then $z^{(2)}$ changes by exactly $W_1^{(2)}$, so the forward weight is also the backward conductor, and the activation slope converts sensitivity in $a$ into sensitivity in $z$. The worked example already shrank $\delta^{(2)} \approx -0.041$ to $\delta^{(1)} \approx -0.004$ — ten times smaller in a single layer.

**58.** On an ill-conditioned ravine — a steep $\theta_2$ wall and a gentle $\theta_1$ floor — plain SGD bounces across the walls and crawls along the floor. What do Momentum and RMSprop each change?

A. Momentum shrinks the step on the steep axis by tracking recent gradient magnitudes, while RMSprop builds a velocity that accumulates along the gentle floor.
B. Momentum lowers the learning rate whenever the loss goes up, while RMSprop restarts the search from the best point it has seen so far.
C. Momentum averages the gradients over the last epoch, while RMSprop averages the parameter values over the last epoch.
**D. Momentum remembers the previous direction, so opposing wall-hits cancel and the along-floor component accumulates; RMSprop remembers recent gradient magnitudes, so the steep axis gets a small step and the flat axis a larger one.**

**Explanation:** SGD zig-zags because the local gradient points mostly across the walls rather than along the floor. Adam is the combination of the two memories — direction plus per-parameter scaling — which is why it traces the straightest path to the minimum.

**59.** Why does initializing every weight in an MLP to zero prevent learning, and what does He initialization address?

A. All the gradients evaluate to exactly zero on the first step so nothing moves, and He initialization restarts training from a random point once that stall is detected.
B. The forward pass returns zero for every input regardless of depth, and He initialization fixes this by setting each bias to a small positive constant instead.
C. The pre-activations become undefined so the first backward pass produces NaN values, and He initialization prevents this by capping each weight at variance $2/n_{\mathrm{in}}$.
**D. Every unit in a layer computes the same $z = b$ and receives the same $\delta$, so the units remain identical clones with no symmetry breaking, while He initialization sets variance $2/n_{\mathrm{in}}$ so ReLU activations and gradients start at a usable scale.**

**Explanation:** Identical units stay identical forever because they see identical forward values and identical error signals, so the network never differentiates its neurons. He/Kaiming is the ReLU-oriented choice, while Xavier/Glorot is the usual pairing for sigmoid and tanh.

**60.** Over which values does BatchNorm compute its statistics compared with LayerNorm, and why is LayerNorm preferred for sequence models and for $B = 1$?

**A. BatchNorm averages down the mini-batch for each feature, so its statistics are noisy or broken at $B = 1$; LayerNorm averages across the features of each individual sample, so it does not depend on the batch at all.**
B. BatchNorm averages across the features of each sample while LayerNorm averages down the batch, so LayerNorm needs fewer statistics whenever sequence lengths vary.
C. BatchNorm normalizes the weights while LayerNorm normalizes the activations, and only weight statistics become unreliable when a batch holds a single sample.
D. BatchNorm normalizes once before training while LayerNorm renormalizes at every step, and only the per-step version stays valid when $B = 1$.

**Explanation:** BatchNorm's statistics run vertically down the batch per feature, which is why it is at home in CNNs but degenerates at batch size one; LayerNorm runs horizontally across a sample's features and is therefore batch-independent, which suits Transformers. Both stabilize activations during training at the cost of extra compute, and neither makes the loss convex.
