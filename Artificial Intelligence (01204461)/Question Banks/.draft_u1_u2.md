## Unit 1 — Introduction, AI Agents, Environments, Knowledge Representation & Expert Systems

**1.** A factory rebuilds its defect detector so that the mapping from sensor readings to "defective / OK" comes from thousands of past labeled inspections instead of being written by an engineer. In the lecture's contrast between classical AI and machine learning, what has changed?

A. The knowledge is still hand-encoded, but the machine now searches it with heuristics such as $A^*$.
**B. The decision rules are now discovered from data instead of being hand-written as IF–THEN statements.**
C. The system now derives conclusions by applying inference rules to a stored knowledge base.
D. The system now treats each inspection as a node in a state space and plans a path to the goal.

**Explanation:** Classical AI means humans encode the rules and the machine searches; machine learning means the rules are learned from data. By Mitchell's definition, performance on the task improves as more experience arrives.

**2.** An interrogator exchanges text messages with a hidden human and a hidden program and cannot reliably tell which is which. Which of the four definitions of AI does this setup test?

A. Thinking humanly, because it models the reasoning steps a person goes through.
B. Thinking rationally, because it checks whether the conclusions follow the laws of thought.
**C. Acting humanly, because it judges observable behavior rather than internal mechanism.**
D. Acting rationally, because it rewards whichever action has the highest expected utility.

**Explanation:** This is Turing's Imitation Game (1950), which sits in the *acting* × *humanlike* cell. It scores behavior only and says nothing about how the program reasons internally.

**3.** The agent function is written $f : P^* \to A$. What does this notation claim about an agent's behavior?

A. It maps the agent's single current percept to the action with the highest utility.
**B. It maps every possible percept history to the action the agent takes in response.**
C. It maps each action the agent takes to the percept the environment returns next.
D. It maps the states of the environment to the sensors that are able to observe them.

**Explanation:** $P^*$ is the full sequence of percepts received so far, and $A$ is the set of possible actions, so $f$ specifies behavior for every history. The agent program is the code that implements $f$ on a particular architecture.

**4.** A self-driving car brakes correctly given everything its sensors reported, but a crate falls from an unseen truck and a crash follows. How is its rationality judged?

A. It was irrational, because a rational agent is expected to achieve the best outcome every time.
B. It was rational only if it had already been trained on this exact kind of accident beforehand.
C. Rationality does not apply, because outcomes in stochastic environments cannot be scored at all.
**D. It was rational, because rationality means maximizing expected performance given available information.**

**Explanation:** Rational is not omniscient — the agent cannot know the future and is judged on the decision it made with the percepts and knowledge it had. It is still expected to learn and gather information when that would improve later decisions.

**5.** Which list belongs in the **P** slot of PEAS for an automated taxi?

A. Cameras, LiDAR, radar, GPS, speedometer, and IMU.
**B. Safety, trip speed, legal compliance, passenger comfort, and fuel efficiency.**
C. Steering, throttle, brake, turn signals, and horn.
D. City streets, other traffic, pedestrians, and weather.

**Explanation:** The performance measure is the objective score of success, not a description of the world or of the hardware. The other three lists are the sensors, the actuators, and the environment.

**6.** Tournament chess is played with a move clock. Along the static–dynamic axis, how is that environment classified?

A. Static, because nothing about the position changes unless a player moves a piece.
B. Dynamic, because the opponent may alter the board at any moment during deliberation.
**C. Semi-dynamic, because the position waits for the agent while the clock keeps running.**
D. Static, because the clock belongs to the performance measure rather than to the environment.

**Explanation:** Semi-dynamic means the world state itself does not change while the agent thinks, but its performance score does — here through elapsed time. Untimed chess is simply static.

**7.** A warehouse robot's camera is blocked whenever it carries a tall box, so the correct turn depends on corridors it saw earlier. Which architecture is the smallest upgrade from a simple reflex agent that fixes this?

**A. A model-based reflex agent, which keeps internal state about what it cannot currently perceive.**
B. A goal-based agent, which searches for a plan that leads toward a desired state.
C. A utility-based agent, which scores outcomes and picks the best among competing goals.
D. A learning agent, which improves through a critic, learning element, and problem generator.

**Explanation:** A simple reflex agent uses only the current percept, so it fails whenever the right action depends on history. Adding internal state for the unobservable part of the world is exactly the model-based reflex step on the ladder.

**8.** What distinguishes $\mathrm{KB} \models \alpha$ from $\mathrm{KB} \vdash \alpha$?

A. $\models$ means $\alpha$ was explicitly told to the KB, while $\vdash$ means $\alpha$ was fetched by an Ask query.
B. $\models$ is syntactic — $\alpha$ is produced by rules such as modus ponens; $\vdash$ is semantic — $\alpha$ holds in all KB models.
C. $\models$ applies only to propositional logic, while $\vdash$ applies only to structured forms such as frames.
**D. $\models$ is semantic — $\alpha$ holds in every model where the KB holds; $\vdash$ is syntactic — $\alpha$ is derived by inference rules.**

**Explanation:** Entailment is a statement about truth in models: wherever the KB is true, $\alpha$ must be true. Inference is a statement about derivation: $\alpha$ can be reached by applying rules such as modus ponens.

**9.** An expert system holds the rule Fever $\land$ Cough $\to$ Flu, is told a patient's fever and cough, and concludes Flu. Where does the conclusion go, and what follows from that?

**A. Into working memory; the knowledge base is untouched, so the system has not learned anything.**
B. Into the knowledge base as a new rule, so later patients can be diagnosed more quickly.
C. Into the knowledge base as a new fact, while working memory is cleared for the next query.
D. Into working memory first, and the engine copies it into the knowledge base once the consult ends.

**Explanation:** The inference engine matches lasting KB rules against this case's facts and writes derived facts back into working memory only. The KB never gets rewritten from a consultation, which is precisely why expert systems cannot learn on their own.

**10.** A plant-monitoring system reacts to a continuous sensor stream, while a diagnostic system must confirm or rule out one named disease using as few tests as possible. Which chaining strategy suits each?

A. Backward chaining for the monitor and forward chaining for the diagnosis.
B. Forward chaining for both, because both begin from facts that have been observed.
**C. Forward chaining for the monitor and backward chaining for the diagnosis.**
D. Backward chaining for both, because both end at a single named conclusion.

**Explanation:** Forward chaining is data-driven: incoming facts fire rules and pile up conclusions, which fits real-time monitoring. Backward chaining is goal-driven: it starts from the hypothesis and only asks for the facts needed to prove it, which fits diagnosis.

## Unit 2 — Supervised Learning

**11.** Which task is a regression problem, judged by the shape of the output space $\mathcal{Y}$?

A. Deciding whether an incoming email is spam or not spam.
**B. Predicting a house's selling price in baht from its area, bedrooms, and age.**
C. Recognizing which of the digits 0–9 is written in an image.
D. Tagging a news article with every topic that it happens to cover.

**Explanation:** Regression means $\mathcal{Y}$ is continuous, e.g. $\mathcal{Y} \subseteq \mathbb{R}$ for a price. The others are binary, multi-class, and multi-label classification, all of which have a discrete $\mathcal{Y}$.

**12.** A price model trained only on Bangkok houses is evaluated on Chiang Mai houses. Which part of the i.i.d. assumption breaks?

A. Independence, because sales in one city are recorded later in time than sales in the other.
B. Independence, because the same houses are likely to appear in both cities' records.
C. Identical distribution, because $P(X,Y)$ has to be written in closed form before training starts.
**D. Identical distribution, because the test examples are drawn from a different $P(X,Y)$ than the training ones.**

**Explanation:** Two markets mean two different joint distributions, so the examples are no longer identically distributed. Independence is the part broken by duplicates or by one example influencing another; $P(X,Y)$ is never known in closed form in any case.

**13.** A gold-price series contains a few extreme spikes, and you care about the typical day rather than the spikes. Which training loss fits, and why?

A. MSE, because squaring the residual keeps the loss smooth and differentiable everywhere.
**B. MAE, because its penalty grows in step with $\lvert e \rvert$, so a single outlier cannot dominate the average.**
C. MSE, because it fits the conditional median and therefore discounts extreme values.
D. MAE, because it has one well-defined gradient at every residual, including $e = 0$.

**Explanation:** MAE is robust and fits the conditional median, while MSE's quadratic growth lets one spike dominate — tripling the error grows the MSE penalty ninefold. MAE's own weakness is the corner at $e=0$, which needs a subgradient.

**14.** Why must a raw linear score $w^\top x$ be squashed by a sigmoid before it is scored with binary cross-entropy?

A. BCE needs a hard 0/1 prediction, and the sigmoid rounds the score to the nearer label.
B. BCE is undefined for negative targets, and the sigmoid makes every label non-negative.
**C. BCE evaluates $\ln(\hat y)$ and $\ln(1-\hat y)$, so its input has to lie strictly inside $(0,1)$.**
D. BCE needs predictions that sum to 1 across the classes, which the sigmoid guarantees.

**Explanation:** $w^\top x$ is unbounded, so it is not a probability and the logarithms would be undefined; the sigmoid maps it into $(0,1)$. That sigmoid + BCE pairing is logistic regression, while summing to 1 across classes is what softmax does.

**15.** Why is zero–one loss used only for reporting rather than for training by gradient descent?

**A. It is a step function whose derivative is zero almost everywhere, so it gives the optimizer no direction.**
B. It grows without bound on confidently wrong predictions, so its gradients explode during training.
C. It requires predicted probabilities, which a classifier that outputs hard labels cannot supply.
D. It averages to the misclassification rate, a quantity that is not comparable across datasets.

**Explanation:** Zero–one loss is flat at 0 and jumps to 1, so every weight setting producing the same hard decisions looks identical to gradient descent. The standard split is to train on a smooth surrogate such as BCE or hinge loss and report accuracy or $F_1$ afterwards.

**16.** Which statement correctly contrasts parametric and non-parametric models?

A. A parametric model must keep the full training set at inference, while a non-parametric one can discard it.
**B. A parametric model has a fixed parameter set and can discard $D$, while a non-parametric model grows with $n$.**
C. Kernel SVM is parametric, because its prediction reduces to one fixed-length weight vector in input space.
D. Decision trees are parametric, because the number of splits is fixed before any training data is seen.

**Explanation:** Parametric models store a fixed $\theta$, so $D$ can be thrown away after fitting; non-parametric models ($k$-NN, trees, kernel SVM) grow with the data and keep $D$ or its support vectors. Kernel SVM counts as non-parametric because prediction depends on a data-dependent set of support vectors.

**17.** Linear regression's squared-error loss is convex. What does that guarantee, and how do the two solution routes differ?

A. There is one global minimum; gradient descent lands on it in a single step, while the normal equations only approximate it iteratively.
B. There may be several local minima; the normal equations pick out the lowest, while gradient descent can halt at any one of them.
**C. There is one global minimum; the normal equations hit it in one shot if $X^\top X$ is invertible, while gradient descent nears it stepwise.**
D. There is one global minimum; both routes need $X^\top X$ to be invertible, so neither one is usable once $d$ grows large.

**Explanation:** Convexity means a single bowl with no local minima to get trapped in. The normal equation $w^* = (X^\top X)^{-1}X^\top y$ is exact but needs an invertible $X^\top X$ and becomes slow for large $d$, whereas gradient descent only needs the gradient and iterates toward the same bottom.

**18.** In logistic regression, predicting class 1 whenever $\sigma(z) \ge 0.5$ is equivalent to which condition on the logit $z$?

**A. $z \ge 0$, because $\sigma(0)=0.5$ and the boundary is the hyperplane $w^\top x = 0$.**
B. $z \ge 0.5$, because the logit crosses its threshold at the same number as the probability.
C. $z \ge 1$, because the sigmoid saturates close to 1 for any logit above that point.
D. $z \le 0$, because negative logits are the ones carrying stronger evidence for class 1.

**Explanation:** The sigmoid is exactly $0.5$ at $z=0$ and increases monotonically, so thresholding the probability at $0.5$ is the same as thresholding the logit at $0$. That makes the decision boundary the hyperplane $w^\top x = 0$.

**19.** How does binary logistic regression generalize to $C>2$ mutually exclusive classes?

A. One logit per class through its own sigmoid, trained with binary cross-entropy for each class.
B. A single logit compared against $C-1$ thresholds, trained with categorical cross-entropy.
C. One logit per class through softmax, trained with zero–one loss over the predicted labels.
**D. One logit per class through softmax, trained with categorical cross-entropy against one-hot targets.**

**Explanation:** Softmax turns the $C$ scores into probabilities that sum to 1, and categorical cross-entropy keeps only the true class's term because the target is one-hot. The pairing to remember is sigmoid + BCE for binary and softmax + CCE for multi-class.

**20.** At each node, CART tries every feature $j$ and threshold $t$ in the split $x_j \le t$. Which candidate does it keep?

A. The split that leaves the two children holding as close to equal numbers of examples as possible.
B. The split with the lowest unweighted average of the two children's impurity scores.
**C. The split with the largest information gain: parent impurity minus the size-weighted impurity of the children.**
D. The split on the feature with the widest raw value range, once the features have been scaled.

**Explanation:** Information gain is $I_{\text{parent}} - (\frac{n_L}{n}I_L + \frac{n_R}{n}I_R)$, and CART keeps the largest one. The children must be weighted by size, and trees need no feature scaling at all.

**21.** What does it mean to call $k$-NN a lazy, instance-based learner?

**A. Training just stores $D$; computing distances and aggregating neighbors happens at query time.**
B. Training fits a compact weight vector, and queries then reuse it without touching the data.
C. Training compresses $D$ into a few cluster centres that queries are compared against.
D. Training and inference are both $O(1)$, since distances are computed once and cached.

**Explanation:** Training is $O(1)$ because it only stores the dataset, and brute-force querying costs $O(nd)$ since every stored point must be measured. Inference is the expensive end, which is why KD-trees or ball trees are used to index the points.

**22.** Among a query's $k=3$ nearest neighbors, two class-A points sit at moderate distance while one class-B point is much closer. How do plain majority voting and $1/d^2$ distance-weighted voting compare here?

A. Both schemes predict A, because weighting rescales every neighbor's vote by the same factor.
B. Both schemes predict B, because the single nearest neighbor always decides the final label.
**C. Plain majority predicts A, while $1/d^2$ weighting can predict B because the nearest point outweighs both A votes.**
D. Plain majority predicts B, while weighting predicts A, because weighting spreads influence to farther points.

**Explanation:** Unweighted voting counts 2–1 for A, but $w_i = 1/(d_i^2+\epsilon)$ gives the closest point far more weight — in the worked example B scores $1.00$ against A's $0.45$. Distance weighting can therefore flip the plain majority.

**23.** In a soft-margin SVM, what is the effect of decreasing the hyperparameter $C$?

A. It forbids margin violations, which turns the problem back into the hard-margin one.
B. It narrows the margin so that fewer training points end up misclassified.
C. It enlarges $\lVert w \rVert$, which widens the gap between the two margin planes.
**D. It tolerates more margin violations in exchange for a wider margin around the boundary.**

**Explanation:** Small $C$ buys a fatter margin by accepting more slack, while large $C$ punishes violations and yields a skinny margin. The margin width is $2/\lVert w\rVert_2$, so a larger $\lVert w\rVert$ would narrow it, not widen it.

**24.** What makes the kernel trick practical on data that no straight line can separate?

**A. Only inner products $\langle \Phi(x_a), \Phi(x_b)\rangle$ are needed, so $\Phi$ never has to be computed explicitly.**
B. $\Phi$ is evaluated once per training point and cached, so each inner product becomes a table lookup.
C. It projects the data into fewer dimensions, where a straight line can separate the classes again.
D. It replaces the margin constraints with slack variables, which lets the boundary bend around points.

**Explanation:** A kernel returns $K(x_a,x_b)=\langle\Phi(x_a),\Phi(x_b)\rangle$ directly, so a linear boundary in the mapped space becomes a curve in the original space without ever forming $\Phi(x)$. Slack variables are the soft-margin idea, a separate mechanism.

**25.** A model reaches very low training error but a much higher test error. What is the diagnosis and a suitable fix?

A. High bias, i.e. underfitting; add capacity or engineer better features.
**B. High variance, i.e. overfitting; gather more data, add regularization, or simplify the model.**
C. The noise floor $\sigma^2$ has been reached, so no further change can improve either score.
D. An optimization failure; lower the learning rate so both errors converge to the same value.

**Explanation:** Test error decomposes into bias$^2$ + variance + $\sigma^2$, and the train–test gap is the variance term. Underfitting instead shows both errors high and close together.

**26.** In $L_{\mathrm{reg}}(w) = L(w) + \lambda\Omega(w)$, what happens as $\lambda$ grows, and how do the two penalties differ?

A. Variance rises and bias falls; L1 encourages sparse weights while L2 discourages large ones.
B. Variance falls and bias rises; L1 discourages large weights while L2 drives many weights to zero.
C. Both bias and variance fall; L1 and L2 differ only in cost to compute, not in the weights they favor.
**D. Variance falls and bias rises; L1 encourages sparse weights while L2 discourages large ones.**

**Explanation:** A larger $\lambda$ constrains the model, trading variance away for bias — less overfitting, more underfitting. L1 (Lasso) $\lVert w\rVert_1$ encourages sparsity, while L2 (Ridge) $\lVert w\rVert_2^2$ shrinks large weights.

**27.** A screening test for a serious disease should miss as few genuinely sick patients as possible. Which metric captures that goal most directly?

**A. Recall, $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$, the share of actual positives that the model catches.**
B. Precision, $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$, the share of predicted positives that are correct.
C. Accuracy, $(\mathrm{TP}+\mathrm{TN})/N$, the share of all predictions that came out correct.
D. $F_1 = 2PR/(P+R)$, which blends precision and recall into one balanced score.

**Explanation:** A missed sick patient is a false negative (type II error), and recall is the metric with FN in its denominator. Precision instead penalizes false alarms, and accuracy can look high while many positives are missed.
