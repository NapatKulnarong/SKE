## Unit 5 — Convolutional Neural Networks & Computer Vision

**61.** In a convolutional layer, what is a single feature map?

A. The stack of all output channels produced by the layer's full bank of filters.
B. The learned weight matrix of one filter, rendered as a small image.
**C. The grid one filter writes, where entry $(i,j)$ scores how strongly that filter's pattern is present there.**
D. The input channel the filter was applied to, after normalization to $[0,1]$.

**Explanation:** A feature map (activation map) is the 2D grid produced by one filter, and each entry answers "how strongly is this filter's pattern present *here*". The stack of all such maps is the output volume, not a single feature map.

**62.** What is the purpose of zero-padding in a convolutional layer?

**A. It adds a border of zeros around the input so the window can reach the edges, controlling how much the output shrinks.**
B. It sets negative activations to zero so the resulting feature maps become sparse.
C. It enlarges the jump of the sliding window so that fewer positions are evaluated.
D. It rescales the pixel intensities into $[0,1]$ before the filter is applied.

**Explanation:** Zero-padding $p$ is a border of zero-valued pixels that lets the window sit on the actual edge of the image. Zeroing negatives is ReLU, and enlarging the jump is stride.

**63.** Why is a non-linear activation such as ReLU applied after each convolution?

A. Because the layer's parameter count would otherwise grow with the depth of the network.
B. Because convolution outputs must be rescaled into $[0,1]$ before pooling can be applied.
C. Because the filter weights would otherwise stop being shared across spatial positions.
**D. Because a stack of convolutions without it collapses into a single linear map.**

**Explanation:** A convolution is a linear dot product, so stacked convolutions without a non-linearity reduce to one linear map — the same collapse seen with linear MLP layers. ReLU also gives sparse maps by zeroing negative pre-activations.

**64.** What is the essential difference between classical computer-vision filters and CNN filters?

A. Classical filters are 3D tensors, whereas CNN filters are 2D weight matrices.
**B. Classical filters have values chosen by a person, whereas CNN filter values are learned by gradient descent.**
C. Classical filters slide across the image, whereas CNN filters are applied to the whole image at once.
D. Classical filters act on color channels, whereas CNN filters act only on grayscale input.

**Explanation:** Both are small weight arrays applied to local patches; the shift is *who chooses the numbers*. Sobel, Gaussian, Gabor and similar kernels are hand-written formulas, while a CNN's weights are initialized and then trained.

**65.** A convolutional layer receives an input volume with 128 channels and uses 3×3 filters. What determines how many channels its output volume has?

**A. The number of filters in the layer, because each 3D filter writes exactly one 2D map.**
B. The number of input channels, because each filter returns one map per input channel.
C. The kernel size, because a 3×3 filter produces nine separate response maps.
D. The stride, because each jump of the window contributes one output channel.

**Explanation:** A filter's depth equals $C_{\mathrm{in}}$, but it sums across channels and still writes a single 2D map. Output channels come from how many filters are stacked, and kernel size is not the number of kernels.

**66.** In $H_{\mathrm{out}}=\left\lfloor\frac{H-k+2p}{s}\right\rfloor+1$, what does the "+1" account for?

A. The bias term that is added to every cell of the output feature map.
B. The extra row and column of zeros contributed by padding on one side.
**C. The window's first placement, since the division only counts the jumps made after it.**
D. The center pixel of the kernel, which the stride does not step over.

**Explanation:** The fraction counts how many strides of $s$ pixels the window can make on the padded grid, and the $+1$ counts the initial position before any jump.

**67.** Why does a convolutional layer's parameter count stay the same whether it processes a 32×32 thumbnail or a 4096×4096 satellite photo?

A. Because larger images are pooled down to a fixed spatial size before the convolution runs.
**B. Because the count depends only on kernel size, input channels and filter count, as one filter is reused everywhere.**
C. Because the biases grow with image size while the kernel weights shrink proportionally.
D. Because padding is chosen so that every input reaches the same effective resolution.

**Explanation:** The count is $(k^2 C_{\mathrm{in}}+1)\,C_{\mathrm{out}}$, which contains no $H$ or $W$ term because weight sharing reuses the same filter at every position. This is a key efficiency advantage over a fully connected layer, whose parameter count does scale with input size.

**68.** Sobel and Laplacian kernels have weights that sum to zero. What does that imply about their response on a perfectly uniform patch?

A. The response equals the constant intensity, because the kernel passes the patch through unchanged.
B. The response equals the patch average, because a zero-sum kernel acts as a local mean.
C. The response is large and negative, because the negative weights dominate on a bright patch.
**D. The response is about zero, because the positive and negative weights cancel over constant intensities.**

**Explanation:** On a flat patch every pixel is multiplied by weights that sum to zero, so the products cancel. A large response appears only where intensity changes quickly, which is exactly what an edge is.

**69.** How does a depthwise convolution differ from a standard convolution?

**A. Each input channel gets its own k×k kernel and is not mixed with the others, so the channel count is unchanged.**
B. One shared k×k kernel is applied to every channel at once, so the output collapses to a single channel.
C. Channels are mixed at a single pixel with one weight per channel, so neighboring pixels are ignored.
D. The kernel slides along the channel axis instead of the spatial axes, so the spatial size is unchanged.

**Explanation:** Depthwise convolution filters spatially per channel with no channel mixing, so $C_{\mathrm{in}}$ is preserved; a standard conv does spatial filtering *and* channel mixing. Mixing can be restored afterwards with a 1×1 conv, giving a depthwise separable convolution.

**70.** On the MNIST comparison, the shallow MLP fell to 4.5% accuracy on digits shifted ±4 pixels while the two-conv CNN still reached 44.6%. What explains the MLP's collapse?

A. It had fewer parameters than the CNN, so it lacked the capacity to represent shifted digits.
B. It pooled its inputs, discarding the location information needed to place a shifted digit.
**C. Each of its weights is tied to a fixed pixel index, so a shifted pattern lands on weights that never learned it.**
D. It used a softmax output, which cannot assign translated images to the same class.

**Explanation:** Flattening destroys adjacency and binds every first-layer weight to one specific pixel index, so nothing transfers when the digit moves. The CNN reuses the same filter at every location, so the pattern is still detected after the shift.

**71.** Global average pooling is often used in place of flattening followed by a large dense layer. What is its main advantage regarding overfitting?

A. It keeps only the strongest activation in each map, so noisy responses are dropped before classification.
**B. It reduces each map to a single number with no learnable weights, removing the dense layer where parameters explode.**
C. It rescales each map to zero mean, which stabilizes the gradients flowing into the dense layers.
D. It randomly zeroes half the activations during training so that units cannot co-adapt.

**Explanation:** GAP turns $H\times W\times C$ into $C$ numbers using no extra weights, so the huge dense layer that usually follows flattening disappears. Keeping the strongest response is max pooling, and random zeroing is dropout.

**72.** In $\mathrm{RF}_l=\mathrm{RF}_{l-1}+(k_l-1)\prod_{i=1}^{l-1}s_i$, why is the new layer's contribution multiplied by the product of all earlier strides?

**A. Layer $l$'s step is measured in the previous layer's grid, and earlier downsampling stretches each step back into input pixels.**
B. Each earlier layer reuses the same kernel, so its size must be counted once per preceding layer.
C. Striding adds padding at every earlier layer, which enlarges the input region the neuron can reach.
D. The product converts the receptive field from a count of input pixels into a count of channels.

**Explanation:** The $(k_l-1)$ extra positions live in layer $l-1$'s coordinate system, and every preceding stride made one of those positions cover several original pixels. Mapping the addition back to the input image therefore scales it by the product of the earlier strides.

**73.** VGG replaces a single 5×5 convolution with two stacked 3×3 convolutions at stride 1. Which statement captures the rationale?

A. The pair covers a larger field than 5×5 with the same parameters, at the cost of one fewer ReLU.
B. The pair covers the same field with an identical parameter count, and the only gain is the extra non-linearity.
C. The pair uses more parameters but gains a translation invariance a single 5×5 layer cannot provide.
**D. The pair covers the same 5×5 field with fewer parameters ($18C^2$ versus $25C^2$) and adds a second ReLU.**

**Explanation:** Two 3×3 layers at stride 1 give a receptive field of $1+2+2=5$, matching one 5×5 layer, while using about 28% fewer weights. The stack also applies two non-linearities instead of one.

**74.** In a ResNet block $y=F(x)+x$, why does this design make very deep networks trainable?

**A. The block only has to learn the residual change $F(x)$, and the $+x$ path carries activations and gradients past it.**
B. The addition halves the block's parameter count, so a 100-layer network costs no more than a shallow one.
C. The addition rescales the block's output to unit norm, preventing activations from exploding with depth.
D. The block drops its non-linearity in favor of an identity map, so no gradient is lost in ReLU's zero region.

**Explanation:** The layers learn only the change from $x$ rather than the whole mapping, and the identity shortcut gives signal and gradient a clean route around the block. That is why networks past 100 layers became trainable.

**75.** You have a small labeled dataset that is visually similar to ImageNet and want to reuse a pretrained CNN. Which strategy does the chapter recommend?

A. Fine-tune every layer at a large learning rate so the pretrained features adapt quickly to the new images.
B. Train from random initialization, since pretrained features would bias the model toward the source classes.
**C. Freeze the pretrained backbone and train only a new final layer, since the existing features already fit the task.**
D. Keep the backbone but discard the pretrained weights of its last blocks and retrain those blocks from scratch.

**Explanation:** Feature extraction — freezing the backbone and training a new head — is the typical choice when the target set is small and similar to the source. Fine-tuning at a small learning rate is reserved for cases with more target data.
