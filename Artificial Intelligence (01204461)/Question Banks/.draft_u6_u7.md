## Unit 6

**76.** An autoencoder is said to be trained in an *unsupervised* way. What makes its training unsupervised?

A. The encoder weights are frozen so that only the decoder learns from the reconstruction error.
B. The latent code $z$ is compared against a stored prototype vector for each class.
**C. The reconstruction target is the input $x$ itself, so no separate labels are needed.**
D. The loss pulls together pairs of inputs that happen to share the same label.

**Explanation:** The loss is $L_{\mathrm{recon}}=\frac1d\lVert x-g_\phi(f_\theta(x))\rVert^2$ — the target *is* the input, so no labels are required. Backprop then updates both the decoder weights $\phi$ and the encoder weights $\theta$.

**77.** In the original GAN formulation, how is the work divided between the two networks?

**A. The generator maps a noise vector to a fake sample, while the discriminator outputs how likely its input is real.**
B. The generator compresses real samples into a latent code, while the discriminator reconstructs them from that code.
C. The generator labels each sample as real or fake, while the discriminator sharpens the samples that pass.
D. The generator and the discriminator both score each input, and the higher of the two scores is emitted.

**Explanation:** $G$ is the counterfeiter: $z\sim\mathcal N(0,I)$ becomes $x_{\mathrm{fake}}=G(z)$. $D$ is the detective, outputting $D(x)\in[0,1]$, the probability that the input is real.

**78.** Which component of an LSTM decides which information from the previous memory should be removed?

A. The input gate, which decides which new candidate information is written into memory.
**B. The forget gate, which decides which content of the previous cell state is dropped.**
C. The output gate, which decides which part of the memory becomes the current hidden state.
D. The cell state, which discards old content as it is carried across time steps.

**Explanation:** The three sigmoid gates split the job: $f_t$ removes old cell content, $i_t$ writes the new candidate, and $o_t$ picks what of $c_t$ becomes $h_t$. The cell state is the memory being edited, not a gate.

**79.** A team stacks dense layers into an autoencoder but leaves out all nonlinear activations, and finds the MNIST reconstructions look essentially like PCA. What explains this?

A. The bottleneck becomes overcomplete, so the network settles on the identity function.
B. The reconstruction loss silently switches to explained variance, which is PCA's objective.
C. Backpropagation cannot reach the encoder, so only the decoder's weights are ever trained.
**D. Stacked linear layers collapse into a single linear map, so the model can only fit a flat subspace, exactly as PCA does.**

**Explanation:** Without a nonlinearity the whole network reduces to $\hat x=W_{\mathrm{dec}}W_{\mathrm{enc}}x+b$ — "PCA with extra steps." ReLU or sigmoid is what lets the encoder follow a curved manifold instead of a flat plane.

**80.** A denoising autoencoder is fed corrupted inputs $\tilde x=x+\mathrm{noise}$. Against what is its loss computed, and why does that remove the noise?

A. Against the corrupted input $\tilde x$, since reproducing the noise pattern is what teaches the encoder to recognize and strip it.
**B. Against the clean input $x$; unstructured noise does not repeat across the training set, so the code keeps structure and drops the noise.**
C. Against the latent code of the clean input, since matching the two codes forces the noisy version to align with it.
D. Against the average of $x$ and $\tilde x$, since averaging keeps the reconstruction stable when the noise is strong.

**Explanation:** The encoder sees $\tilde x$, but the loss is still measured against the clean $x$. Because unstructured noise does not repeat the same way across samples, the bottleneck has no reason to encode it.

**81.** A factory has thousands of images of defect-free chips and almost no labeled defects. How does an autoencoder-based inspector flag a cracked chip it has never seen?

A. Train on both normal and defective chips, then classify each new image by the sign of its latent code.
B. Train on normal chips only, then flag any chip whose latent code has a larger norm than the training average.
**C. Train on normal chips only, then flag any chip whose reconstruction error exceeds a threshold $\tau$.**
D. Train on normal chips only, then flag any chip whose reconstruction saturates the top of the pixel range.

**Explanation:** With only normal data in training, the decoder never learned to draw a crack, so $\lVert x_{\mathrm{test}}-\hat x_{\mathrm{test}}\rVert^2$ spikes on a defect. The anomaly score exceeding $\tau$ is the decision rule.

**82.** Why do GAN samples typically look sharper than autoencoder reconstructions of the same kind of data?

A. The generator uses a much larger latent vector than an autoencoder's bottleneck, so more fine detail survives compression.
B. The generator reconstructs each training image directly, while an autoencoder can only approximate it from a compressed code.
C. The generator's transposed convolutions preserve high-frequency detail that an autoencoder's dense decoder layers discard.
**D. The generator is trained against a learned loss — the discriminator punishes texture that looks wrong — while MSE rewards the pixel-wise average of all plausible reconstructions.**

**Explanation:** A standard autoencoder minimizing MSE converges on the smooth average of everything plausible, which smears hair, fabric, and leaves. A GAN's loss is learned by $D$ rather than fixed, so blur that "looks wrong" is penalized.

**83.** Modern LLMs are built from Transformers rather than LSTMs, even though both are trained on next-token prediction. What is the limitation of the recurrent approach?

**A. The hidden state must be updated left to right, so training does not parallelize, which limits context length and model scale.**
B. The recurrent form cannot express $P(w_t\mid w_1,\ldots,w_{t-1})$, so it needs an extra classifier head bolted on.
C. The recurrent form requires hand-labeled next tokens, while Transformers learn the same task without labels.
D. The recurrent form discards its hidden state each step, so it cannot condition on more than one previous token.

**Explanation:** RNNs and LSTMs update $h_t$ sequentially, and that scan does not parallelize, which caps context and model size. Attention and Transformers keep the same next-token objective but allow parallel training.

**84.** The GAN objective is $\min_G\max_D V(D,G)=\mathbb E_{x\sim p_{\mathrm{data}}}[\log D(x)]+\mathbb E_{z\sim p_z}[\log(1-D(G(z)))]$. How should the two players' aims be read?

A. Both networks maximize $V$, so training converges once each has reached its own separate optimum.
B. $D$ minimizes $V$ by pushing $D(x)$ toward $0$ on real samples, while $G$ maximizes the same $V$ by keeping $D(G(z))$ close to $0$ on its fakes.
**C. $D$ maximizes $V$ by pushing $D(x)$ toward $1$ on real samples and $D(G(z))$ toward $0$ on fakes, while $G$ minimizes the same $V$ by driving $D(G(z))$ toward $1$.**
D. Both networks minimize $V$, so the shared value falls to zero once the fakes become realistic.

**Explanation:** The two players share one number and pull it in opposite directions: $D$ wants $V$ large (correct real/fake calls), $G$ wants it small. At the ideal end $D(x)\approx0.5$ on both real and fake inputs.

**85.** The LSTM cell state update is $c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t$. Why does this form help gradients survive many time steps?

A. The sigmoid gates lie in $(0,1)$, so the product $f_t\odot c_{t-1}$ grows at each step and offsets the shrinking gradient.
B. The cell state is recomputed from scratch at each step, so gradients never have to travel through earlier steps at all.
C. The hidden state is thrown away after each step, leaving one short gradient path through the output gate.
**D. New information enters through an additive term rather than a long chain of multiplications, so the path from $c_{t-1}$ to $c_t$ stays open over many steps.**

**Explanation:** A vanilla RNN multiplies the recurrent weight at every step during BPTT, driving the gradient toward zero. The additive "highway" in the cell state avoids that long product, so information and gradient can travel far back.

## Unit 7

**86.** An MDP is written $\mathcal M=(\mathcal S,\mathcal A,P,R,\gamma)$. What does $\gamma$ represent?

A. The probability of reaching a particular next state given the current state and action.
B. The learning rate, which sets how much of each correction is applied to an estimate.
**C. The discount factor, which sets how much weight future rewards carry relative to immediate ones.**
D. The exploration rate, which sets how often the agent takes a random action.

**Explanation:** In the 5-tuple, $P$ is the transition model, $R$ the reward function, and $\gamma\in[0,1)$ the discount factor weighting future rewards. The learning rate $\alpha$ and exploration rate $\epsilon$ belong to the learning algorithm, not to the MDP.

**87.** What distinguishes reinforcement learning's feedback signal from supervised learning's?

A. Supervised feedback arrives once per batch, while a reward arrives only once per dataset.
B. Supervised feedback is numeric, while a reward is categorical and must be decoded into a class.
C. Supervised feedback is optional during training, while a reward is mandatory at every step.
**D. Supervised feedback is a label stating the correct answer, while a reward states only how good the chosen action was.**

**Explanation:** A label tells the learner *what* the right answer was; a reward tells it only *how good* its choice turned out. The agent still has to work out for itself which action would have been better.

**88.** In tabular Q-learning, how is the Q-table laid out, and what does acting greedily correspond to?

A. Rows are actions and columns are states; acting greedily takes the largest value down the current action's column.
**B. Rows are states and columns are actions; acting greedily takes the largest value along the current state's row.**
C. Rows are episodes and columns are time steps; acting greedily replays the action from the best-scoring episode.
D. Rows are states and columns are rewards; acting greedily takes the action with the largest immediate reward.

**Explanation:** $Q$ is a 2-D lookup with rows indexed by state and columns by action, so greedy action selection is $a^*=\arg\max_aQ(s,a)$ — the row maximum. Note this maximizes estimated long-term return, not immediate reward.

**89.** Blackjack dealt from a finite deck that is never reshuffled violates the Markov Property when the state is just the player's hand total. Why, and what is the standard fix?

A. Because the dealer acts after the player, so the state must include the dealer's hidden card.
B. Because the reward arrives only at the end of the hand, so the state must include the running score.
**C. Because the cards already dealt change what remains in the deck, so the state must include the count of dealt cards.**
D. Because the legal actions change from turn to turn, so the state must include the list of currently allowed actions.

**Explanation:** The Markov Property requires that history add nothing once $(s,a)$ is known, but past deals still change the future here. The fix is to enlarge the state so it carries everything relevant, i.e. the count of dealt cards.

**90.** An agent must keep learning on a server load balancer, a task that never terminates. Which update method is required, and why?

A. Monte Carlo, because averaging complete returns is the only unbiased way to score a continuing task.
**B. Temporal-difference, because it updates after every step, whereas Monte Carlo would wait for an episode end that never arrives.**
C. Monte Carlo, because it needs no transition model, whereas temporal-difference bootstraps from $P(s'\mid s,a)$.
D. Temporal-difference, because it stores the full trajectory and replays it whenever the task is interrupted.

**Explanation:** Monte Carlo is episodic-only since it needs the actual return $G_t$ from a finished episode. TD works for episodic *and* continuing tasks because it updates online from $R_{t+1}+\gamma V(S_{t+1})$.

**91.** What is the dividing question between model-based and model-free RL?

**A. Whether the agent uses $P(s'\mid s,a)$ and $R(s,a)$ to predict outcomes and plan, rather than learning values straight from experience.**
B. Whether the agent stores its value estimates in a lookup table or in a neural network.
C. Whether the agent learns a policy directly or learns a value function first.
D. Whether the agent updates after every step or only after a complete episode.

**Explanation:** Model-based methods predict $(s',r)$ and plan with that model; model-free methods such as Q-learning and SARSA go straight from experience to values or a policy. The other three options describe different axes: representation, value-vs-policy, and MC-vs-TD.

**92.** Under an $\epsilon$-greedy policy, which statement about the action probabilities is correct?

A. The greedy action is taken with probability exactly $1-\epsilon$, because exploration always selects a different action.
B. Every action is equally likely whenever $\epsilon>0$, greedy or not.
C. The greedy action's probability rises as the action set grows, because $\epsilon$ is spread more thinly over the alternatives.
**D. Exploration draws from all actions, so the greedy action can be drawn again, giving it slightly more than $1-\epsilon$.**

**Explanation:** The exploratory draw is uniform over the whole action set, so $P(\text{greedy})=(1-\epsilon)+\epsilon/\lvert\mathcal A\rvert$ and each other action gets $\epsilon/\lvert\mathcal A\rvert$. That extra term shrinks, not grows, as the action set gets larger.

**93.** Q-learning and SARSA share the same TD structure. Where exactly do their updates differ?

A. Q-learning discounts the next state's value, while SARSA uses that value undiscounted.
B. Q-learning updates after every step, while SARSA waits until the episode has finished.
**C. Q-learning uses the best Q-value available in $s'$, while SARSA uses the Q-value of the action actually selected in $s'$.**
D. Q-learning follows an $\epsilon$-greedy behavior policy, while SARSA is forced to act greedily.

**Explanation:** The targets are $r+\gamma\max_{a'}Q(s',a')$ versus $r+\gamma Q(s',a')$ — only the next-state term differs. Both can run the very same $\epsilon$-greedy behavior policy.

**94.** In the Q-learning update, why is $\max_{a'}Q(s',a')$ taken to be $0$ when $s'$ is terminal?

**A. Because no future reward can follow a terminal state, so the target reduces to the immediate reward.**
B. Because the Q-table is reset to zeros at the beginning of every new episode.
C. Because the discount factor is set to zero for the last transition of an episode.
D. Because terminal states are left out of the Q-table, so their row is undefined and treated as empty.

**Explanation:** A terminal state has no future, so its value is $0$ and the TD target collapses to $r$. That is exactly the `0.0 if done else np.max(Q[s_next])` line in the gridworld code.

**95.** How do the Monte Carlo and TD targets compare in bias and variance?

A. MC is biased but low-variance because averaging complete returns smooths episode-to-episode noise, while TD is unbiased but high-variance because its target shifts every step.
**B. MC is unbiased but high-variance because the actual return carries every future step's randomness, while TD is biased but lower-variance because its target is one real reward plus an imperfect estimate.**
C. Both targets are unbiased, and TD's lower variance comes entirely from using a smaller learning rate rather than from the target itself.
D. Both targets are biased, and MC's higher variance comes from bootstrapping on estimates that are still changing during training.

**Explanation:** $G_t$ is the true return, so MC is unbiased, but it accumulates randomness from every future step. TD's target contains only one real reward plus the estimate $V(S_{t+1})$, which is stabler but may be wrong — and MC does not bootstrap at all.

**96.** What changes when tabular Q-learning is replaced by Deep Q-Learning (DQN)?

**A. Only the representation of $Q$ changes, to a network $Q_\theta(s,a)$; the TD target and action selection from $Q$ stay the same.**
B. The agent becomes model-based, because the network predicts the next state before an action is chosen.
C. The TD target is replaced by the full Monte Carlo return, because networks need complete episodes to train.
D. Action selection switches from $\arg\max$ over $Q$ to sampling from a softmax policy head.

**Explanation:** DQN exists because a table needs one entry per $(s,a)$, which is impossible for large or continuous state spaces such as raw game images. The Q-learning framework around the network is unchanged.

**97.** Why is $Q^*$ more convenient than $V^*$ for choosing actions in a model-free setting?

A. Because $Q^*$ is bounded in $[0,1]$ while $V^*$ is unbounded, which makes comparisons across actions numerically safer.
B. Because $V^*$ is defined only for episodic tasks, while $Q^*$ also covers continuing tasks.
**C. Because $Q^*$ already folds in the dynamics and future return for each action, so acting is a row lookup, while choosing from $V^*$ needs $P(s'\mid s,a)$.**
D. Because $Q^*$ is learned without a discount factor, so its ranking of actions does not depend on $\gamma$.

**Explanation:** Acting from $V^*$ requires $\arg\max_a\sum_{s'}P(s'\mid s,a)[R+\gamma V^*(s')]$ — that is, the model. With $Q^*$ the rule is just $\pi^*(s)=\arg\max_aQ^*(s,a)$, an $O(\lvert\mathcal A\rvert)$ lookup with no model.

**98.** In Cliff Walking, SARSA learns the longer route away from the edge while Q-learning learns the shortest path along it. Why?

A. SARSA uses a smaller discount factor, so the distant goal matters less to it and a longer, safer route becomes acceptable.
B. SARSA explores with a larger $\epsilon$, so it sweeps more of the grid and happens to find the upper route first.
C. SARSA is model-based, so it predicts the falls from its transition model and plans a route around the cliff edge.
**D. SARSA evaluates the exploratory behavior it actually follows, so occasional random steps make the edge look costly, while Q-learning's $\max$ evaluates a greedy policy that never slips.**

**Explanation:** SARSA is on-policy: its target uses the action really selected, exploration included, so the safer 17-step route wins. Q-learning is off-policy and learns the greedy policy's value, giving the optimal 13-step edge path even though it falls while exploring.

**99.** In the $2\times2$ gridworld, the goal's reward first shows up in the Q-value of the cell next to the goal and reaches the start cell only on a later pass. What does this illustrate?

A. That the learning rate must be decayed over time, or early updates would overwrite later ones.
**B. That bootstrapping carries value backward one step per update, because each update reads the current estimate of the next state.**
C. That the $-0.1$ step cost prevents value from travelling more than one cell per episode.
D. That the Q-table must be swept in reverse order from the terminal state for updates to be valid.

**Explanation:** Each update uses $\max_{a'}Q(s',a')$, so a state can only inherit value that its successor already holds. The goal's reward therefore propagates backward one step at a time, pass after pass.

**100.** Why must a continuing task use $\gamma<1$ rather than $\gamma=1$?

A. With $\gamma=1$ the TD target collapses to the immediate reward, so the agent becomes short-sighted.
B. With $\gamma=1$ the discount weights $\gamma^k$ grow with $k$, so distant rewards dominate nearby ones.
C. With $\gamma=1$ the Q-values leave the numeric range that a lookup table is able to represent.
**D. With $\gamma=1$ and a constant per-step reward, every non-terminating policy scores an infinite return, so policies cannot be ranked.**

**Explanation:** In a continuing task with constant reward, $\gamma=1$ gives $G_t=\infty$ for every policy, which makes them indistinguishable. Discounting keeps $G_t$ finite; note it is $\gamma=0$, not $\gamma=1$, that makes the agent short-sighted.
