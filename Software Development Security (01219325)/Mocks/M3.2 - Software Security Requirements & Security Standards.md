>***Note:** STRIDE is a threat-modeling framework (developed at Microsoft) used to categorize security threats by type. Each letter represents a category of threat:*
>
>- **Spoofing**: Pretending to be someone/something else (e.g. faking identity/credentials)
>- **Tampering**: Maliciously modifying data or code
>- **Repudiation**: Denying you performed an action, without proof to contradict it
>- **Information Disclosure**: Exposing information to someone not authorized to see it
>- **Denial of Service**: Disrupting or blocking legitimate access to a system
>- **Elevation of Privilege**: Gaining higher-level access/permissions than you should have
