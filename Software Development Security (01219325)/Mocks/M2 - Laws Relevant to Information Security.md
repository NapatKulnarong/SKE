**1.** In Thailand’s hierarchy of law, a lower law:

- [ ] A. Can override a higher law if parliament votes for it
- [ ] B. Always **overrides** a higher law during an emergency
- [x] C. Cannot override a higher law; higher laws always override lower ones
- [ ] D. Overrides the Constitution if it is a Ministerial Regulation

**2.** The **supreme** law of the land is:

- [ ] A. An Act of parliament
- [x] B. The Constitution
- [ ] C. A Code of Law (Civil/Commerce, Penal, Land)
- [ ] D. A Ministerial Regulation

**4.** An **Emergency Decree** is described as enabling:

- [ ] A. Local-level rules only
- [x] B. State-of-emergency powers (curfews, censorship, evacuations)
- [ ] C. Automatic copyright in source code
- [ ] D. A Data Protection Officer

**5.** **Palace Law** sits separately because it:

- [ ] A. Overrides the Constitution for the general public
- [x] B. Governs royal succession, **not** laws for the general public
- [ ] C. Is a Ministerial Regulation under the Penal Code
- [ ] D. Is the same as an Emergency Decree

**8.** Criminal law is interpreted **by the letter of the law**. Commerce (civil) law is interpreted:

- [ ] A. Also by the letter only
- [x] B. By the **intention** behind the law
- [ ] C. Only by the NCSC
- [ ] D. Only if GDPR Article 22 applies

**9.** For software engineers, **computer crime laws** (and some privacy fines) sit under **criminal** law, while **contracts and intellectual property** sit under:

- [ ] A. Local/subordinate laws only
- [ ] B. Palace Law
- [x] C. Commerce (civil) law
- [ ] D. Section 14 of the Computer Crimes Act

**10.** International recognition of privacy in this lecture is tied to:

- [ ] A. PDPA Section 73 only
- [x] B. Article 12 of the UN Universal Declaration of Human Rights (privacy, family, home, correspondence)
- [ ] C. APPI’s definition of pseudonymized data
- [ ] D. Creative Commons Share-Alike

**11.** Under GDPR Article 4, **processing** means:

- [ ] A. Only storing data in the EU
- [x] B. Anything done to data: collect, store, alter, share, delete
- [ ] C. Only automated decision-making (Art. 22)
- [ ] D. Only transferring data to another service

**12.** The **controller** decides why and how data is processed. The **processor**:

- [ ] A. Advises on compliance and is the contact point for regulators
- [x] B. Processes data **on the controller’s behalf**
- [ ] C. Always owns the copyright in the dataset
- [ ] D. Is optional under GDPR but required under APPI

**13.** GDPR **consent** must be:

- [ ] A. Implied by using the website, even if bundled
- [x] B. Freely given, specific, informed, unambiguous
- [ ] C. Given only by someone aged 10 or older
- [ ] D. The same as a trade secret waiver

**14.** A **DPO** (Data Protection Officer):

- [ ] A. Is explicitly required by APPI, not GDPR
- [x] B. Advises on compliance, monitors adherence, and is a contact point for regulators
- [ ] C. Decides why and how data is processed (that is the processor)
- [ ] D. Issues Emergency Decrees

**18.** GDPR applies to **EU data subjects, anywhere in the world**. PDPA applies to:

- [ ] A. EU data subjects only
- [x] B. Anyone **physically in Thailand**
- [ ] C. Anonymized data under APPI only
- [ ] D. State actors with no exemptions

**19.** GDPR’s minimum age is **16** (can be lowered to 13). PDPA’s minimum age in the lecture is:

- [x] A. 16
- [ ] B. 13
- [ ] C. 10
- [ ] D. 18

**20.** Compared with GDPR, APPI:

- [x] A. Requires a DPO and fully defines pseudonymized data
- [ ] B. Defines anonymized and retained personal data, but **not** pseudonymized data; has **no** explicit DPO requirement; data portability and erasure are weaker/less defined
- [ ] C. Applies only to EU data subjects
- [ ] D. Sets minimum age at 10

**24.** **Section 14** (spreading false information) is flagged because it is:

- [ ] A. Never used in practice
- [x] B. **Very frequently invoked**, often in defamation claims, with a vague definition and overlap with other laws
- [ ] C. Only about wiretapping (that is Section 8)
- [ ] D. The same as PDPA Section 73

**25.** **Section 15** also punishes:

- [ ] A. Controllers who fail to appoint a DPO
- [x] B. Platforms/providers that **“allow” Section 14 violations**; an unclear safe-harbor situation
- [ ] C. Clean-room reverse engineering of trade secrets
- [ ] D. Using an LGPL library without forking it

**27.** **Copyright** in creative work is **automatic** (no registration). Pushing code to GitHub:

- [ ] A. Does not count as publication
- [x] B. Counts as **legal publication**
- [ ] C. Grants a software patent
- [ ] D. Waives all trade secrets worldwide

**28.** A **trade secret** protects against corporate espionage but **not** against:

- [ ] A. Copyright infringement
- [x] B. **Clean-room reverse engineering**
- [ ] C. Trademark misuse
- [ ] D. Section 9 data alteration

**29.** **GPL (copyleft)** means if you build something using GPL-licensed code, your **entire project** must also be GPL. **LGPL** is looser: if you **only use** (import) an LGPL library:

- [ ] A. Your entire project must still be GPL
	- [x] B. Your own project can stay under **any** license; you don't need to open-source it
- [ ] C. You must register a patent
- [ ] D. Share-Alike still infects the whole app like GPL

**30.** **Dark patterns** are manipulative UI/UX that trick users into actions they would not otherwise take. They matter here because many exist to extract **PII**, linking UX to **privacy law**. Separately, **reidentification** risk means:

- [ ] A. Anonymized or aggregated data is automatically privacy-safe
- [x] B. Even “anonymized” or aggregated data can be traced back by **cross-referencing** tables or when **group sizes are small**
- [ ] C. Only Section 14 false information can reidentify a person
- [ ] D. Trade secrets prevent joining a voter list to a ballot table
